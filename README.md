# 多层薄膜反射/透射实验台

光学课程用的**纯浏览器**多层薄膜仿真工具：Vue 3 + TypeScript 管理膜层与方案，
mathjs 做复数传输矩阵计算，Plotly.js 绘制光谱与角扫描，IndexedDB 本地存档。
**无后端、无网络请求**，构建产物可直接静态托管或用 `file://` 打开。

## 运行

```bash
npm install
npm run dev       # 本地开发
npm run build     # 类型检查 + 生产构建（dist/）
npm run preview   # 预览构建产物
npm test          # 物理基准 / 插值 / 内置算例端到端 / 组件冒烟 四组测试
```

## 物理模型

- **方法**：特征矩阵法（MacLeod《Thin-Film Optical Filters》）。
  膜层 j 的相位厚度 δ_j = (2π/λ) ñ_j d_j cosθ_j，
  光学导纳 η_s = ñ cosθ（s/TE）、η_p = ñ / cosθ（p/TM）；
  总矩阵 [B; C] = M₁M₂…M_m·[1; η_s]，
  r = (η₀B − C)/(η₀B + C)，R = |r|²，
  T = Re(η_s)/Re(η₀)·|t|²（法向时间平均能流比）。
- **约定**：时间因子 e^{−iωt}，复折射率 ñ = n + i k，**k > 0 表示吸收**。
  因此特征矩阵非对角元为 −i（与部分教材 e^{+iωt} 形式相反）；
  符号与折射率约定必须一致，否则吸收层会算出 R > 1 的非物理结果
  （该约定由金膜算例 R≈0.81/T≈0.08 守护，曾在开发中真实抓到过此错误）。
- **角度**：广义 Snell 定律 ñ_j sinθ_j = ñ₀ sinθ₀（复数），自动处理
  吸收层复折射角与全内反射（TIR 时 cos 取虚分支，R=1, T=0）。
- **偏振**：s 与 p 分别计算，不做混合（非偏振光实测 ≈ 两者平均，需自行取均值）。
- **色散**：给定 (波长, n, k) 数据表，对 n、k 分别**线性插值**；
  查询超出表范围时按端点钳制并在界面明确警告，不做隐式外推。
- **能量守恒**：无损膜系 R + T = 1（测试中偏差 ~1e-16）；
  **吸收介质 R + T < 1，差额 A = 1 − R − T 即真实吸收份额，绝不强制归一**。
  注意入射介质必须无损，否则“入射能流”无标准定义——界面会给出警告。

| 量 | 单位 |

| 波长、膜厚 | nm |

## 内置解析算例（`src/lib/examples.ts`，一键载入并自动核对）

1. **单层四分之一波增透膜**：空气 | MgF₂(λ/4) | BK7。550 nm 反射率
   对照独立闭式公式（四分之一波导纳递推 Y = n₁²/n_s）。
2. **对称 λ/4 多层膜**：H L H（TiO₂/MgF₂）。反射峰对照导纳递推，
   并给出扩展为五层 H L H L H 后的 R₅ 参考值供手动加层对照。
3. **掠入射 / 布儒斯特 / 全反射边界**：裸 BK7 界面，89° 掠入射 R→1、
   布儒斯特角（≈56.6°）R_p = 0、玻璃→空气超过临界角 R = 1/T = 0，
   全部对照独立实现的 s/p 菲涅耳公式。
4. **吸收介质**：50 nm 金膜（Johnson–Christy 选点）@600 nm，
   断言 A > 0.10——演示能量缺口是物理结果，而非守恒失败。

“从谱峰追到膜层参数”：结果区自动列出 R 的主要峰/谷，点击即把探针移到该波长；
调整某层厚度/材料后观察峰位与峰高变化（λ/4 谷位满足 λ₀ ≈ 4nd）。

## 模型能力边界（界面中常驻声明）

- 每层均匀、各向同性、非磁性、界面理想平整；**不含**粗糙度散射、厚度不均、
  膜层扩散/氧化、磁光、各向异性、非线性、增益、近场耦合（SPP/棱镜耦合）。
- 全相干平面波模型：厚基底或宽谱实测中的非相干平均条纹无法复现。
- 内置金属 n,k 为教学选点（450–1000 nm），精度不足以做镀膜定量设计；
  定量研究请导入完整材料数据库（材料库支持 CSV 粘贴：每行 `波长nm,n,k`）。
- **结果是理想模型预测，不是任何实物镀膜的实测性能**；与实物不一致时
  以实测光谱为准，并检查模型假设是否被违反。
