# 多层薄膜反射/透射实验台（纯浏览器）

光学课程用薄膜光谱实验台：复数特征（传输）矩阵法计算多层膜的 R/T/A 光谱，
s/p 偏振分别处理，材料色散查表插值，方案保存在浏览器 IndexedDB。**无后端，不上传任何数据。**

## 运行

```bash
npm install
npm run dev        # 开发
npm run build      # 构建（dist/ 可静态部署）
npm run test       # 解析算例与能量守恒的自动化验证（vitest，12 例）
```

## 物理模型

- 特征矩阵法：每层 M_j = [[cosδ, i·sinδ/η],[i·η·sinδ, cosδ]]，δ = (2π/λ)·ñ·d·cosθ̃；
  [B;C] = (∏M_j)·[1;η_sub]，r = (η₀B−C)/(η₀B+C)，t = 2η₀/(η₀B+C)。
- 导纳：s 偏振 η = ñcosθ̃；p 偏振 η = ñ/cosθ̃。R = |r|²，T = Re(η_s)/Re(η₀)·|t|²，A = 1−R−T。
- 复折射率：材料数据为 (n, κ)，κ>0 表吸收；内部采用 Macleod 约定 ñ = n−iκ（e^{iωt}）。
  吸收介质中折射角为复数（Snell 定律 ñ_j sinθ̃_j = ñ₀sinθ₀），平方根分支取衰减波。
- 复数运算由 mathjs 完成。

## 单位约定

| 量 | 单位 |
|---|---|
| 波长 λ | nm |
| 膜层厚度 d | nm（物理厚度） |
| 入射角 θ | 度（°，自法线起算，< 90°） |

## 能量守恒

- 无损膜系：R+T=1 在数值精度内成立，界面实时显示 max|R+T−1|。
- 含吸收介质：A = 1−R−T > 0，**不强制 R+T=1**；谱图自动增绘 A 曲线。
- 无损膜 + 半无限吸收基底：R+T=1 仍成立（T 为进入基底并在其中耗散的能流）。

## 解析算例（界面一键载入，且由 vitest 自动核对）

1. **单层四分之一波膜**：空气/MgF₂(λ₀/4)/BK7，λ₀=550nm，
   解析 R = ((n₀nₛ−n₁²)/(n₀nₛ+n₁²))²。
2. **对称多层高反堆 (HL)⁵H**：解析等效导纳 Y = n_H¹²/(n_L¹⁰·nₛ)，R = ((n₀−Y)/(n₀+Y))²。
3. **掠入射边界**：裸 BK7 界面 0→89.5° 角扫描，R_s、R_p 与 Fresnel 公式逐点一致，
   R_p 在布儒斯特角过零，θ→90° 两者均→1；θ=90° 为模型奇异点，程序拒绝计算。

## 谱峰溯源

点击谱图任意点，显示该 (λ, θ) 处各膜层的 n、κ、光学厚度 n·d、λ/4 倍数 q
（无损层含 cosθ̃ 斜入射修正；吸收层标注复相位），并标记接近四分之一波/半波的层，
帮助从谱峰位置反推膜层参数。

## 模型边界（不冒充实物镀膜）

平面波、平行平面突变界面、各向同性均匀膜、完全相干；基底半无限（不含背面反射与非相干叠加）；
内置材料表为教学示例数据、线性插值、超范围取端点并警告。所有谱线为模型计算结果，
不代表任何实际镀膜产品的测量值。
